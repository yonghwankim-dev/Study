## 대칭키와 비대칭키
### Encryption types
대칭키 암호화 방식 - Symmetric Encryption (Shared)
- 같은 key를 사용함
- 같은 key를 이용하여 암호화 및 복호화 함

비대칭키 암호화 방식 - Asymmetric Encryption (RSA Keypair)
- 비공개키, 공개키 사용
- 공개키로 암호화하고 비공개키로 복호화 함
- Java key 툴 사용

설정 저장소에 암호화된 데이터를 저장하고 Spring Cloud Config Server를 거처셔 마이크로서비스에게 전달될 때는 복호화된 데이터를 전달합니다.

## 비대칭키를 이용한 암호화 - keytool
- 공개키로 암호화하고 비공개키로 복호화하는 방식을 비대칭키 암호화 방식입니다.
- public, private key를 생성하기 위해서 JDK keytool을 사용합니다.

keystore 디렉토리 생성
```shell
mkdir /Users/yonghwankim/Documents/keystore
```

key 생성 명령어
이 명령어는 **Java Keytool**을 이용해서 **RSA 비대칭키 쌍을 생성하고**, 그 결과를 **JKS(Java KeyStore)** 파일(`apiEncryptionKey.jks`)로 저장하는 명령입니다.
```shell
keytool \
-genkeypair \
-alias apiEncryptionKey \
-keyalg RSA \
-dname "CN=Yonghwan Kim, OU=API Development, O=yonghwanconsulting.co.kr, L=Daejeon, C=KR" \
-keypass "1q2w3e4r" \
-keystore apiEncryptionKey.jks \
-storepass "1q2w3e4r"
```

config-service의 bootstrap yaml 파일 수정
- 기존 대칭키 값이 아닌 비대칭키를 사용하기 위해서 비대칭키 저장된 곳에 대한 설정을 함
```yaml
encrypt:  
  key-store:  
    location: file://${HOME}/Documents/keystore/apiEncryptionKey.jks  
    password: 1q2w3e4r  
    alias: apiEncryptionKey  
```
