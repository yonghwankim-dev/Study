## 컨테이너 가상화
### Virtualization
물리적인 컴퓨터 리소스를 다른 시스템이나 애플리케이션에서 사용할 수 있도록 제공
- 플랫폼 가상화
- 리소스 가상화

하이퍼바이저(Hypervisor)
- Virtual Machine Manager(VMM)
- 다수의 운영체제를 동시에 실행하기 위한 논리적 플랫폼
- Type1 : Native or Bare-metal
- Type2 : Hosted

### Container Virtualization
OS Virtualization
- Host OS 위에 Guest OS 전체를 가상화
- VMWare, VirtualBox
- 자유도가 높으나, 시스템에 부하가 많고 느려짐

Container Virtualization
- Host OS가 가진 리소스를 적게 사용하며, 필요한 프로세스 실행
- 최소한의 라이브러리와 도구만 포함
- Container의 생성 속도 빠름

### Container Image
Container 실행에 필요한 설정 값
- 상태값 x, Immutable

Image를 가지고 실체화 한것 -> Container

이미지를 저장하고 있는 Public/Private Registry 저장소에서 이미지를 가져와서 Container로 실행할 수 있습니다.

### Dockerfile
- Docker Image를 생성하기 위한 스크립트 파일
- 자체 DSL(Domain-Specific Language) 언어 사용 -> 이미지 생성 과정 기술

```dockerfile
FROM mysql:5.7

ENV MYSQL_ALLOW_EMPTY_PASSWORD true
ENV MYSQL_DATABASE mydb

ADD ../db_mount /var/lib/mysql

EXPOSE 3306

CMD ["mysqld"]
```

## 컨테이너 생성과 실행
### Docker 실행
```shell
docker run -d -p 3306:3306 -e MYSQL_ALLOW_EMPTY_PASSWORD=true --name mysql mysql:5.7
```
- mysql 5.7 버전은 루트 계정의 비밀번호를 지정해야 하는데, 이를 해결하기 위해서는 MYSQL_ALLOW_EMPTY_PASSWORD 옵션을 true로 설정해야 합니다.

mysql 컨테이너 배시 쉘 실행
```shell
docker exec -it mysql bash
```

## Docker 이미지 생성과 Public registry에 Push
### Dockerfile for Users Microservice
- https://hub.docker.com/

user-service dockerfile 스크립트 파일 작성
```dockerfile
FROM openjdk:8-jdk-alpine

VOLUME /tmp

COPY target/users-ws-0.1jar users-service.jar

ENTRYPOINT ["java", "-Djava.security.egd=file:/dev/./urandom", "-jar", "users-service.jar"]
```
- `-Djava.security.egd`
	- JVM이 난수(PRNG, SecureRandom)를 생성할 때 어떤 엔트로피 소스를 사용할지 지정하는 설정
	- Spring Boot, JWT, HTTPS 통신, 세션 ID 생성 등 **보안 난수**가 필요한 모든 로직에 영향을 줍니다.
- `file:/dev/./urandom`
	- JVM 버그(구버전) 때문에 위와 같이 설정함
	- 예전 JVM은 `file:/dev/urandom`을 `file:/dev/random`으로 fallback(잘못 매핑)하는 버그가 있었음
	- `/dev/./urandom`처럼 경로를 "정확히 다른 경로"로 입력하면 JVM이 **정확히 urandom을 사용함**
	- JVM이 무조건 **논블로킹 난수 소스(/dev/urandom)** 을 사용하게 만들기 위한 우회 설정


docker 이미지 빌드
- 현재 디렉토리(.)에 위치한 dockerfile을 가지고 이미지를 생성합니다.
```shell
docker build -t yh951107/user-service:1.0 .
```

docker 이미지 푸시
- docker 이미지를 원격 저장소로 업로드합니다.
```shell
docker push yh951107/user-service:1.0
```

docker 이미지 가져오기
- docker 이미지를 원격 저장소로부터 가져옵니다.
```shell
docker pull yh951107/user-service:1.0
```

### dockerfile 생성
user-service 프로젝트 위치에 Dockerfile 생성

Dockerfile 작성
```Dockerfile
FROM openjdk:21-ea-jdk-slim  
VOLUME /tmp  
COPY target/user-service-1.0.jar UserService.jar  
ENTRYPOINT ["java","-jar","/UserService.jar"]
```

프로젝트 컴파일 및 빌드
```shell
mvn clean
mvn compile
mvn package
```
