
## 컴포넌트 생성 및 중첩하기
React는 마크업을 반환하는 자바스크립트 함수입니다.
마크업(Javascript XML, JSX)은 HTML 코드로 렌더링하기 전의 설계도입니다.
다음 함수는 MyButtion이라는 이름의 컴포넌트입니다. 
```js
function MyButton() {
  return (
    <button>I'm a button</button>
  );
}
```

React 컴포넌트는 다른 컴포넌트안에 중첩시킬 수 있습니다. 예를 들어 MyApp이라는 컴포넌트 안에 MyButton 컴포넌트를 중청시키면 다음과 같습니다.
```js
export default function MyApp() {
  return (
    <div>
      <h1>Welcome to my app</h1>
      <MyButton />
    </div>
  );
}
```

`export default` 키워드를 적용하면 해당 파일의 기본 컴포넌트를 지정합니다.

## JSX로 마크업 작성하기
마크업 문법을 JSX라고 합니다. 대부분의 React 프로젝트는 JSX를 사용합니다.
컴포넌트는 여러개의 JSX 태그를 반환할 수 없기 때문에 `<div>...</div>` 또는 `<>...</>`처럼 감싸는 부모 태그로 감싸야 합니다.

```js
function AboutPage() {
  return (
    <>
      <h1>About</h1>
      <p>Hello there.<br />How do you do?</p>
    </>
  );
}
```

### 스타일 추가하기
React에서는 `className`으로 CSS 클래스를 설정합니다.
```js
<img className="avatar" />
```

별도의 CSS 파일에서 CSS 규칙을 설정합니다.
```css
/* In your CSS */
.avatar {
  border-radius: 50%;
}
```

## 데이터 표시하기
JSX를 사용하면 자바스크립트에 마크업을 넣을 수 있습니다. 중괄호를 사용하면 코드에서 일부 변수를 삽입할 수 있습니다.
```js
return (
  <h1>
    {user.name}
  </h1>
);
```

다음과 같이 애트리뷰트에 중괄호를 사용하여 변수값을 넣을 수 있습니다. "avatar"는 고정된 상수 문자열이지만, `user.imageUrl`은 변수로써 참조되어 주입됩니다.
```js
return (
  <img
    className="avatar"
    src={user.imageUrl}
  />
);
```

다음과 같이 user 객체를 생성한 다음에 "+" 연산자를 이용하여 문자열끼리 연결할 수 있습니다.
```js
const user = {
  name: 'Hedy Lamarr',
  imageUrl: 'https://i.imgur.com/yXOvdOSs.jpg',
  imageSize: 90,
};

export default function Profile() {
  return (
    <>
      <h1>{user.name}</h1>
      <img
        className="avatar"
        src={user.imageUrl}
        alt={'Photo of ' + user.name}
        style={{
          width: user.imageSize,
          height: user.imageSize
        }}
      />
    </>
  );
}

```

`style={{}}`은 `style={}` JSX 중괄호안에 존재하는 일반 `{}` 객체입니다. 즉, 즉석에서 객체를 생성해서 주입하는 것입니다.

## 조건부 렌더링
`if` 문을 사용하여 특정 조건에 따라서 JSX를 포함시킬수 있습니다. 예를 들어 다음 코드를 보면 로그인된 상태라면 AdminPanel 컴포넌트를 포함시키고, 아니라면 LoginForm 컴포넌트를 포함시킵니다.
```js
let content;
if (isLoggedIn) {
  content = <AdminPanel />;
} else {
  content = <LoginForm />;
}
return (
  <div>
    {content}
  </div>
);
```

`if`문대신에 조건부 삼항 연산자 사용 가능합니다.
```js
<div>
  {isLoggedIn ? (
    <AdminPanel />
  ) : (
    <LoginForm />
  )}
</div>
```

`else` 분기가 필요치 않으면 `&&` 연산자도 사용 가능. isLoggedIn 값이 true인 경우에만 AdminPanel 컴포넌트 포함시킵니다.
```js
<div>
  {isLoggedIn && <AdminPanel />}
</div>
```

## 리스트 렌더링하기
`for`문 또는 `map()` 함수를 이용하여 컴포넌트 리스트를 렌더링할 수 있습니다. 예를 들어 다음 코드는 products 리스트와 `map` 함수를 이용하여 렌더링하는 코드입니다.
```js
const products = [
  { title: 'Cabbage', id: 1 },
  { title: 'Garlic', id: 2 },
  { title: 'Apple', id: 3 },
];

const listItems = products.map(product =>
  <li key={product.id}>
    {product.title}
  </li>
);

return (
  <ul>{listItems}</ul>
);
```

`<li>` 에 key 애트리뷰트를 설정하여 고유한 식별자를 설정합니다. 

## 이벤트에 응답하기
컴포넌트 내부에 **이벤트 핸들러 함수**를 선언하여 이벤트에 응답 가능. 예를 들어 버튼을 클릭했을때 handleClick 함수 호출하도록 다음과 같이 구현
```js
function MyButton() {
  function handleClick() {
    alert('You clicked me!');
  }

  return (
    <button onClick={handleClick}>
      Click me
    </button>
  );
}
```
위 코드에서 `onClick={handleClick}`과 같이 끝에 소괄호 없이 전달만 합니다. 만약 `onClick={handleClick()}`과 같이 전달하면 handleClick 함수가 바로 실행될 것입니다. 함수는 반환값이 없으므로 `onClick={undefined}`가 될것입니다.
비유하면 요리사에게 내가 배고프면 이 레시피(handleClick)로 요리해달라고 레시피를 전달해주는 것입니다. 그러면 요리사는 바로 레시피를 사용하여 요리를 해주는 것이 아닌 사용자가 배고플때(버튼을 클릭할때) 그제서야 레시피를 이용하여 요리해줄 것입니다.

## 화면 업데이트하기
컴포넌트가 특정 정보를 기억하기 위해서 컴포넌트에 `State` 를 사용합니다.

useState 가져오기
```js
import { useState } from 'react';
```

`State` 변수 선언
count 변수에 0값이 초기화됩니다. setCount 변수는 count 변수를 수정할 수 있는 함수입니다.
```js
function MyButton() {
  const [count, setCount] = useState(0);
  // ...
```

예를 들어 버튼을 클릭하면 `setCount` 함수를 사용하여 count의 값을 1씩 증가시킵니다.
```js
function MyButton() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <button onClick={handleClick}>
      Clicked {count} times
    </button>
  );
}
```
`setCount` 함수가 호출되면 React가 컴포넌트를 다시 호출합니다. 이러면 카운트 값이 1에서 2로 증가됩니다.

다음과 같이 여러개의 동일한 MyButton 컴포넌트를 추가하면 각각의 MyButton 컴포넌트가 독립적인 count 값을 가집니다.
```js
import { useState } from 'react';

export default function MyApp() {
  return (
    <div>
      <h1>Counters that update separately</h1>
      <MyButton />
      <MyButton />
    </div>
  );
}

function MyButton() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <button onClick={handleClick}>
      Clicked {count} times
    </button>
  );
}
```

## Hook 사용하기
`use`로 시작하는 함수를 `Hook` 이라고 합니다. `useState`는 React에서 제공하는 내장 Hook입니다.

## 컴포넌트 간에 데이터 공유하기
이전 예시에서는 MyButton 컴포넌트에 각각 독립적인 count 값이 있었습니다. 예를 들어 첫번째 버튼을 클릭하면 첫번째 MyButton 컴포넌트의 count값이 1로 증가하고 두번째 MyButton 컴포넌트의 count 값은 0으로 유지됩니다.
![](imgs/Pasted%20image%2020260214220602.png)

하지만 데이터를 공유하고 항상 함께 업데이트하기 위한 컴포넌트도 필요한 경우도 있습니다.
예를 들어 두 MyButton 컴포넌트가 동일한 count 값을 표시하고 업데이트하려면 State를 개별 버튼에서 모든 버튼이 포함된 가장 가까운 컴포넌트로 위쪽으로 이동하여야 합니다.
![](imgs/Pasted%20image%2020260214220814.png)

위 그림을 구현하기 위해서 코드를 다음과 같이 구현
```js
export default function MyApp() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <div>
      <h1>Counters that update separately</h1>
      <MyButton />
      <MyButton />
    </div>
  );
}

function MyButton() {
  // ... we're moving code from here ...
}
```

위 상태에서 MyButton 컴포넌트에 count와 handleClick 함수를 전달합니다.
```js
export default function MyApp() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <div>
      <h1>Counters that update together</h1>
      <MyButton count={count} onClick={handleClick} />
      <MyButton count={count} onClick={handleClick} />
    </div>
  );
}
```

위 코드에서 MyButton 컴포넌트에 전달된 count, onClick 애트리뷰트를 `props` 라고 합니다.

MyButton 컴포넌트 안에 버튼을 클릭하면 count값이 1씩 증가합니다. 이런것을 **`State` 끌어올리기** 라고 합니다. 완성된 코드는 다음과 같습니다.

```js
import { useState } from 'react';

export default function MyApp() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <div>
      <h1>Counters that update together</h1>
      <MyButton count={count} onClick={handleClick} />
      <MyButton count={count} onClick={handleClick} />
    </div>
  );
}

function MyButton({ count, onClick }) {
  return (
    <button onClick={onClick}>
      Clicked {count} times
    </button>
  );
}

```
