
## 실습 환경 구축

npm과 npx의 차이
- npm(node package manager), npx(node package execute)
- npm은 노드 패키지 관리자, node.js의 모든 패키지와 모듈을 관리하며, CLI 클라이언트 npm으로 구성
- npm 5.2.0 버전부터 새로 추가된 도구가 npx이다. npm을 좀더 편하게 사용하기 위해 npm을 제공해주는 하나의 도구이다.
- npm을 통해 패키지를 실행하려면 package.json에 해당 패키지를 지정하고 로컬에 설치해야 함
- npx는 패키지를 설치하지 않고도 실행할 수 있으며, npm 패키지 러너이므로, 아직 설치되지 않은 패키지가 있으면 자동으로 설치됩니다.
- npm은 패키지를 설치하는데 사용하는 도구
- npx는 패키지를 실행하는데 사용하는 도구
- 정리
	- npm은 패키지 관리자, 전역적
	- npx은 패키지 실행자, 일회성

node.js
- 브라우저 밖에서도 자바스크립트를 실행할 수 있게 해주는 환경(Runtime)
- node.js를 이용해서 자바스크립트 언어 기반으로 서버를 만들거나 프로그램 개발 가능


react 프로젝트 생성
```shell
npx create-react-app my-app
```

react 애플리케이션 시작
```shell
npm start
```

## props
컴포넌트에 프로퍼티를 지정하여 컴포넌트 생성시 프로퍼티 값을 주입할 수 있습니다.
다음 코드를 보면 Header 컴포넌트에 title 프로퍼티를 정의 및 값을 설정한 것을 볼수 있습니다.
```shell
<Header title="REACT"></Header>
```

컴포넌트 정의 부분에서 다음과 같이 매개변수를 통하여 주입받고 불러올 수 있습니다.
```shell
function Header(props){
	console.log('props', props, props.title)
	return <header>
		<h1><a href="/">{props.title}</a></h1>
	</header>
}
```

컴포넌트에 리스트 타입의 객체 주입하기
다음 코드의 topics 리스트를 보면 json 형식으로 생성되었고 Nav 컴포넌트에 주입하는 것을 볼수 있습니다.

주입된 리스트는 props를 통해서 다음과 같이 참조가 가능합니다.
그리고 리스트에 원소를 넣을때 key 프로퍼티를 정의하여 주입해야지 경고가 발생하지 않습니다.
![](imgs/Pasted%20image%2020260210110321.png)

정리
- props를 통하여 컴포넌트에 값을 주입할 수 있습니다.
- 리스트의 원소를 추가시 key 프로퍼티를 정의하여 해당 리스트안에서 유니크한 값을 가져야 합니다.

## state
컴포넌트에서 입력은 props입니다. 리턴값을 React 라이브러리가 렌더링한 html 코드가 됩니다.

props과 state의 차이점
- props는 컴포넌트를 사용하는 외부자를 위한 데이터
- state는 컴포넌트를 만드는 내부자를 위한 데이터

onChangeMode 이벤트를 수행하여도 App 함수는 다시 실행되지 않기 때문에 값은 변하지 않습니다.
useState의 0번째 원소는 초기값이고, 1번째 원소는 값을 변경하는 함수입니다.

useState 초기화
주석처리한 3줄의 코드와 맨 밑에 1줄의 코드는 같은 기능의 코드입니다.
![](imgs/Pasted%20image%2020260210113050.png)

setMode 호출
- setMode를 호출하게 되면 App 컴포넌트가 다시 실행되게 됩니다.
![](imgs/Pasted%20image%2020260210114211.png)

숫자를 태그의 프로퍼티(속성)로  넘기면 숫자가 문자열 타입이 된다. 예를 들어 t.id의 값이 숫자여도 a 태그의 id 프로퍼티로 주입하면 문자열 타입이 됩니다.
![](imgs/Pasted%20image%2020260210114053.png)

정리
- props는 컴포넌트를 사용하는 외부자를 위한 데이터
- state는 컴포넌트를 만드는 내부자를 위한 데이터
- useState를 이용하여 state를 초기화할 수 있다
- setState 함수를 이용하여 컴포넌트를 다시 호출할 수 있습니다.
- 프로퍼티에 주입되는 숫자는 문자열로 저장된다.

newValue = {...value}
- 이렇게 하면 value State의 값이 newValue로 복제된다.

리스트 값 추가 방법
```js
const [value, setValue] = useState([1])
newValue = [...value]; // value 배열 복제
newValue.push(2); // 새로운 원소 추가
setValue(newValue); // 새로운 배열 덮어쓰기
```

Primitive type 값 수정 방법
```js
const [value, setValue] = useState(1); // 1로 초기화
setValue(2); // 2로 변경
```

정리
- `[...value]`를 사용하면 해당 값을 복사하여 저장한다.

## Update
사용자가 읽기 모드인 상태에서 네이게이션 바 중에 하나를 선택할 때 Update 링크 버튼에 "/update/{number}" 경로 추가
Update 버튼을 클릭하는 경우에 모드를 UPDATE로 변경합니다.
![](imgs/Pasted%20image%2020260210151845.png)

App 컴포넌트에서 UPDATE 모드인 경우 Update 컴포넌트를 호출하여 content 변수에 저장합니다.
Update 기능은 수정 기능이기 때문에 Update 화면에 들어가면 선택한 원소의 title과 body가 입력되어 있어야 합니다.
Update 컴포넌트를 호출할때 title과 body를 props로 주입합니다. title과 body 값을 구한 방법은 네비게이션 요소중 하나를 클릭했을때 onChangeMode가 수행되어 id값이 선택된 요소의 id값으로 설정되었습니다. 그래서 설정한 id를 기반으로 topics 리스트를 순회하여 동일한 id를 가진 topic를 탐색하고 title과 body 값을 저장합니다.
onUpdate 이벤트 수행시 매개변수로 수정된 title과 body를 매개변수로 받고 업데이트된 updatedTopic 객체를 생성합니다.
그리고 newTopics 복사본을 이용하여 업데이트를 수행합니다. 그리고 업데이트를 완료하면 READ 모드로 변경합니다.
![](imgs/Pasted%20image%2020260210152006.png)

Update 컴포넌트 구현
- 폼창에 있는 title, body 입력창에 props.title, props.body를 직접적으로 사용하면 수정할수 없습니다. 이는 사용자가 직접 주입해주었기 때문에 고정되버립니다.
- 이 문제를 해결하기 위해서는 onChange 이벤트를 추가하고 setState를 호출하여 수정해야 합니다.
![](imgs/Pasted%20image%2020260210153422.png)
