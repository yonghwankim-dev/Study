
React 컴포넌트는 단일 JSX Element를 반환해야 합니다. 만약 여러개의 JSX Element를 배치하였다면 Fragement(`<>``</>`)를 추가하여 해결할 수 있습니다.
```js
export default function Square() {
  return (
    <>
      <button className="square">X</button>
      <button className="square">X</button>
    </>
  );
}
```

클로저(Closure)
자바스크립트에서 내부 함수가 외부 함수에 정의한 변수 및 함수에 접근 가능한 특징
다음 코드를 보면 Squre 컴포넌트에 존재하는 버튼을 클릭하면 onSqureClick 함수가 실행됩니다.
Squre 컴포넌트에 전달된 onSqureClick 함수가 실행되면 handleClick 함수를 실행합니다.
**handleClick 함수가 실행되면 내부 함수로써 외부 함수(Board)에 정의된 squares 객체와 setSquares 함수에 접근해서 실행하는 것을 볼수 있습니다.** 이렇게 handleClick 함수가 Board 함수의 변수와 함수에 접근해서 실행하는 특징을 클로저라고 합니다.
```js
function Square({value, onSquareClick}){
  return <button className="square" onClick={onSquareClick}>
    {value}
  </button>;
}

export default function Board() {
  const [squares, setSquares] = useState(Array(9).fill(null));

  function handleClick(i){
    const nextSquares = squares.slice();
    nextSquares[i] = "X";
    setSquares(nextSquares);
  }
  return (
    <>
      <div className="board-row">
        <Square value={squares[0]} onSquareClick={() => handleClick(0)}/>
        <Square value={squares[1]} onSquareClick={() => handleClick(1)}/>
        <Square value={squares[2]} onSquareClick={()=>handleClick(2)}/>
      </div>
```

### 빌트인 컴포넌트
리액트 라이브러리가 사용자에게 기본적으로 제공해주는 내장 컴포넌트를 의미합니다.
예를 들어 Fragment `<>`...`</>`, `<StrictMode>`, `<Suspense>`, `<Profiler>` 컴포넌트가 있습니다.

### 이벤트 함수 컨벤션
React에서 이벤트를 의미하는 Prop에는 onSomething을 사용하고, 이벤트를 처리하는 함수를 정의할때는 `handleSomthing`과 같은 이름을 사용합니다.
예를 들어 다음 Square 컴포넌트 사용시 onSquareClick은 이벤트 자체를 의미하고, handleClick 함수는 사각형 클릭시 실제 처리하는 함수입니다.
```js
<Square value={squares[0]} onSquareClick={() => handleClick(0)}/>
```
